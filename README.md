# 🎨 ATS Outreach Ops (Frontend)

A premium, high-performance dashboard for managing influencer discovery, reviewing leads, and tracking outreach campaigns.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js (v18+)
- Backend server running on port 8081

### 2. Installation
```bash
npm install
```

### 3. Configuration
Create a `.env` file in the root directory:
```text
VITE_API_URL=http://localhost:8081/api
```

### 4. Development Mode
```bash
npm run dev
```

## 🛠️ Tech Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Tailored Premium Aesthetics)
- **Icons**: Google Material Symbols
- **State Management**: React Hooks + API Services

## 🌟 Key Features
- **Campaign Management**: Define discovery criteria and target cities.
- **Lead Pipeline**: View unified influencers with platform-specific scoring.
- **Outreach Console**: Track email delivery, replies, and meeting status.
- **Affiliate Tracking**: Generate and manage conversion codes.
